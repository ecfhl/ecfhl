# ECFHL

East Coast Fantasy Hockey League history website.

This repository is the new database-backed version of **ecfhl.win**. The application is designed for Railway deployment with MySQL.

## Planned data model

- Seasons
- Franchises and owners
- Standings
- Players
- Draft picks
- Trades and contract terms
- Awards and trophies
- Playoff results

## Stack

- PHP 8.3
- Laravel 12
- MySQL
- Railway
